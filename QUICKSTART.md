# 🚀 REDÉPLOIEMENT RAPIDE

## La réponse simple :

Pour redéployer le site, il suffit de :

```bash
git add .
git commit -m "Mise à jour du site"
git push origin main
```

Le site sera automatiquement mis à jour sur GitHub Pages en 2-3 minutes !

## ⚙️ Configuration GitHub Pages (une seule fois)

1. Allez sur : https://github.com/waner1er/erwan-rivet/settings/pages
2. Sélectionnez :
   - **Source** : `GitHub Actions` (recommandé) ou `Deploy from a branch`
   - **Branch** : `main`
3. Sauvegardez
