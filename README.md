# erwan-rivet

Portfolio personnel d'Erwan Rivet - Développeur Web PHP / Laravel / WordPress

## 🚀 Déploiement

Ce site est automatiquement déployé sur GitHub Pages via GitHub Actions.

### URL du site
Le site sera accessible à l'adresse : `https://waner1er.github.io/erwan-rivet/`

### Configuration requise
1. Activez GitHub Pages dans les paramètres du dépôt (Settings > Pages)
2. Sélectionnez "GitHub Actions" comme source de déploiement
3. Le workflow se déclenchera automatiquement à chaque push sur la branche `main`
